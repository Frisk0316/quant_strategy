# 工作週誌 2026-07-27(一)〜 2026-08-02(日)

本週主軸:唯一通過統計驗證的「Deribit 選擇權波動率狀態策略」推進到測試網
實單執行;一週內登記並誠實測完十多個新策略假說(絕大多數被資料或統計關卡
擋下);把外部資料面大幅擴充(FRED 總經、CFTC 持倉、CBOE 波動率、跨交易
所選擇權收集器),為之後的假說解鎖鋪路。

## 7/27(一)— Deribit 選擇權資料強化

- 改為保留 Deribit 完整選擇權鏈與波動率原始資料(先前只留聚合值),並新增
  30 天實現波動率衍生序列。
- 選擇權成交流加上「價內/價平/價外」分類,以成交當下的相對行權價判定,
  供後續依 moneyness 分組的假說使用。
- 修正兩個回填 bug:歷史回填改用正確的 history 端點、依請求起始時間自動
  選擇端點。
- API 層修正:「資料庫斷線」與「查無資料」回應不再混淆。
- 執行一輪預先登記的策略發掘回測;整理 GenAI 策略管線的架構決策記錄與
  session 交接文件。

## 7/28(二)— 波動率策略向實單邁進

- 起草並通過「平行軌道實單執行層」架構決策:為已驗證的選擇權波動率策略
  建立下單通道,預設僅連測試網、實際下單功能未啟用。
- Codex 完成該執行層實作;審查通過,並新增兩條審查規則與一條不變式。
- 發現 shadow 模擬的時鐘停擺(Windows 排程任務靜默失敗),記錄失敗證據,
  並為排程視窗加上桌面通知提醒。
- 登記四個「依 moneyness 分組的 Deribit 波動率」假說,取得授權執行探測。

## 7/29(三)— 假說大清洗 + 執行層修復(單日 20+ 筆 commit)

- 實單執行層修復:訂單取消競態的對帳、孤兒單清理、強制最短掛單時間;
  修復 shadow 排程的電源條件與 exit code 被遮蔽的問題;每日 shadow 作業
  自動 promote 蠟燭資料,不再因缺資料而整輪停擺。
- 四個 moneyness 波動率假說全部在第二階段篩選被擋(其中一個與既有家族
  重複被合併),過程中發現參考資料過期,重生後誠實記錄全部失敗。
- 事件類假說兩件:資金費率結算效應探測後被否決;清算反轉假說因無免費
  歷史資料,登記為前向收集等待累積。
- 為滿足「單輪至少八個新機制」的管線要求,從文獻篩選登記八個新假說並
  全部跑完第二階段探測:分鐘級週期性動能(毛利遠低於手續費,否決)、
  到期日 gamma 效應(Deribit 逐筆資料每小時只留前 20 筆,樣本不完整,
  資料擋下)、FOMC 會議漂移與跨資產風險狀態(FRED 序列尚未入庫,資料
  擋下)、兩個與既有家族高度相關直接合併不重複計算試驗數、殘差均值
  回歸成為唯一晉級候選。
- 審查並接受本輪八個實驗登記,對兩個重複假說做家族歸屬裁定。

## 7/30(四)— 資料策略決策

- 規劃三個資料解鎖任務(選擇權逐筆保留、FRED 接入、CME 評估)。
- 評估後建議「不購買 CME 資料」:日頻資料無法檢驗日內假說的主張,買了
  也解決不了問題;省下訂閱費。

## 7/30〜8/2(四〜日)— 資料解鎖執行與驗收(8/2 批次入庫)

- 修好 Deribit 選擇權逐筆資料的分頁遺漏 bug:當分頁邊界落在同一毫秒內
  的多筆成交中間時,剩餘成交會被永久跳過(先前誤判為上游資料改版)。
  改為包含式邊界加成交 ID 去重,並新增「只補 payload 不改聚合值」模式,
  凍結的統計值不再於重跑時被改寫;每小時資料現在保留全部逐筆成交。
- FRED 總經序列正式入庫:2 年期美債殖利率、VIX、美元指數各約 1,600 個
  交易日,黃金因 FRED 停更改用期貨收盤替代序列——這解除了 FOMC 漂移與
  跨資產風險兩個假說的資料封鎖(重跑探測待授權)。
- 測試網激活:Deribit 測試網開放依訊號自動下單(僅限測試網的例外授權,
  不涉及實盤關卡);Binance 期貨測試網與 OKX 模擬盤連通煙霧測試通過;
  範例環境檔明訂「僅交易權限、不可提幣、與實盤金鑰分離」的憑證規範。
- 新假說登記:「跨交易所選擇權隱含波動率離散度」——用 OKX/Bybit/Deribit
  三家的 30 天平價隱含波動率分歧度作為避險訊號,在流動性好的永續合約上
  執行。因三家的免費歷史資料不存在,建置每小時前向收集器(含 30 天定
  價內插、25-delta 風險反轉、完整鏈保留),Windows 排程已註冊,自 8/2
  起開始累積,約九個月後才有足夠樣本誠實開測。同時決議不購買第三方
  歷史資料回填。
- 接入兩個免費高價值資料源:CFTC 期貨持倉週報(標普/十年債/美元指數/
  黃金 2006 起、CME 比特幣 2018 起,發布時間嚴格用週五而非基準日週二,
  避免前視偏誤)與 CBOE 波動率期限結構(VIX 回溯至 1990,加 9 天/3 個
  月/6 個月期限;put/call 比率官方已於 2019 停更,如實停在該處不用爬蟲
  替代)。17 個資料集全部落地 TimescaleDB,經獨立驗證通過(單位正規化、
  發布時間不變式、範圍完整性)。
- 搶在 8/1 付費牆生效前,存檔 NAAIM 主動經理人曝險指數 20 年完整歷史
  (2006〜2026 共 1,050 週)。
- 全部工作分五批 commit 並推送;新增測試 11 項全過,全套單元測試 1,065
  項通過(唯一失敗為前端既有問題,與本週改動無關)。
