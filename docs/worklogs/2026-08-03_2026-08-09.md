## 8/3(一)— 工作目錄現況(尚未 commit,僅供參考)

工作目錄裡另外躺著一批別的協作工作留下的檔案,還沒有整理進 commit,
不屬於這篇週誌的整理範圍,先記下現況供之後接手的人參考:

- 一批用免費資料做的新策略探測:用維基百科文章瀏覽量趨勢、鏈上資料
  (Coin Metrics)、穩定幣脫錨、跨資產顯著度、CFTC 期貨持倉、總體經濟
  殖利率變化等七個題材各自做了一輪探測性回測。結果全部沒有通過嚴謹的
  統計把關——一開始有三個看起來通過了中間的檢定力門檻,但事後稽核發現
  回測程式把 BTC 和 ETH 誤算成兩筆獨立下注(應該算一筆),修正這個計數
  錯誤之後,這三個也都沒通過。這輪一開始就講明是資源有限的「不完整」
  探測,結果不能拿來當作可以上模擬倉或實單的依據。另外 Coin Metrics
  的免費資料授權條款寫明只能非商業用途,之後如果要正式使用得先確認
  授權範圍。
- OKX 不需要金鑰的公開市場資料(委託簿、成交、資金費率)背景收集排程
  已經設定好並跑起來,四個交易對、三種資料都確實有落地;還要再看跑滿
  一整天之後的日誌和硬碟用量,才能決定資料要保留多久、要不要搬移備份。
- 資金費率套利策略在 Binance 與 OKX 模擬(demo)帳戶上的下單/取消流程
  修好了;目前實測到的資金費率年化約 0.229%,本來就低於進場門檻,所以
  正確地沒有下單。但這個策略要下兩腳(現貨 + 永續合約),不是同時成交
  保證,萬一只成交一腳,目前還沒有訂出因應規則,長時間跑之前得先補上。

## 下週可以繼續做的方向

1. 決定上面三批還沒 commit 的工作要不要整理進 commit、找誰 review——
   目前都還只是躺在工作目錄裡。
2. 資金費率套利策略「兩腳只成交一腳」的因應規則要先設計、補上防呆測試,
   才能考慮長時間掛著跑。
3. Coin Metrics 免費資料的授權只能非商業使用,如果要繼續用在這批新策略
   探測上,得先確認授權範圍再決定。
4. OKX 公開資料收集排程跑滿一天後,檢查用量與磁碟成長速度,再決定保留
   多久、要不要另外備份/搬移。
5. Deribit 選擇權歷史資料回補跟資料庫既有存量對不上帳(差了幾筆聚合
   數字)的問題還沒解決,需要使用者和 Claude 一起裁示要復原成回補前的
   數值、接受上游資料被改過、還是改用「只補逐筆資料不動已凍結統計數字」
   的做法——這件事會擋住後續的歷史資料回補工作,需要使用者拍板。
6. 還有一條先前資料工作收尾用的獨立分支,目前只等人工 review 後合併回
   主線,沒有新的技術問題卡著,單純是排隊等審核。
